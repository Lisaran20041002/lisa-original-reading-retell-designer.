# Visual Rules

- 风格：英美儿童绘本插画 × 教师手工剪贴 worksheet × 水彩/彩铅纸面质感。
- 质感：可见干笔颗粒、彩铅边缘、局部不均匀颜料、哑光印刷纸；拒绝光滑数字厚涂。
- 纸面：暖象牙/奶油米白底，轻纤维纹理；灰蓝、鼠尾草绿、杏黄、淡粉为结构色，砖橘/珊瑚/芥末为少量强调色。
- 版式：信息类型决定版式；允许横向选择题、人物图鉴、连续电影格、语言区、故事板与开放留白并存。
- 装饰：局部使用撕纸、胶带、刷痕、箭头、植物、木牌、草丛、栅栏；不能平均铺满或遮挡信息。
- 角色：每张图必须遵守 Character Lock；背景压低，角色可更鲜明但不可霓虹。

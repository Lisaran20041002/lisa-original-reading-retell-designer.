# WORKFLOW

| 阶段 | AI 负责 | Lisa 负责 |
|---|---|---|
| 输入整理 | OCR、文本提取、页码定位、事实标注 | 确认教材版本与教学对象 |
| 教材诊断 | 叙事结构、语言负荷、关键事件分析 | 确认教学重点 |
| 任务设计 | 生成模块候选、支架梯度、学生文案 | 选择删改任务与课堂节奏 |
| 角色/场景锁定 | 建立 Lock 表并标出不确定项 | 确认角色身份和视觉母样 |
| 视觉资产地图 | 把人物、事件、道具、地点和干扰图映射到具体任务 | 确认图量与教学必要性 |
| 插图先行生产 | 在排版前生成实际图片文件、逐图 QA、返修并保存 | 确认最终图与事实准确性 |
| 视觉闸门 | 确认图片文件齐全且覆盖理解、筛选、组织、表达 | 确认可以进入复述单生成 |
| 版式组装 | 围绕已验收插图按学习动作组织页面 | 确认审美、图文密度和可打印性 |
| 最终验收 | 输出双 QA 报告和风险项 | 做最终教学与品牌判断 |

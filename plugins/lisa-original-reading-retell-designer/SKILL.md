# Lisa Original Reading · Retell Designer

Use this skill for reading lessons, textbook screenshots, or PDFs that need a scaffolded retell worksheet.

Run the Teaching Engine and Visual Engine separately, then merge only after both pass review.

## Teaching Engine

1. Inspect the source and preserve facts supported by the original text/images.
2. Diagnose audience, language load, narrative structure, characters, setting, change, and teachable vocabulary.
3. Convert the narrative into understanding → selecting → organizing → expressing.
4. Let the text determine task modules; use a progression from big picture and characters to events, sequencing, supported retell, and independent retell.
5. Reuse source language and keep cognition medium with medium-low language load unless specified otherwise.
6. Remove support gradually: modeled recognition → choices/frames → ordered prompts → keywords → independent oral output.

## Visual Engine

Create Character Lock and Scene Lock before illustration prompts. Generate 3–5 independent pedagogical event illustrations before composing the worksheet. Re-stage teaching meaning; never redraw textbook panels literally.

Direct: soft watercolor-and-colored-pencil storybook illustration, visible dry-brush texture, uneven pigment, matte printed-paper finish, imperfect outlines, warm ivory paper, muted dusty pastel palette, restrained terracotta/sage/powder-blue/faded-mustard/blush accents, natural whitespace.

Let the learning action determine the visual form. Do not use identical rounded cards or a symmetrical grid. Use collage paper, tape, brush marks, arrows, labels, plants, fences, and props locally and purposefully.

## Forbidden visual direction

flat vector illustration; corporate infographic; Canva worksheet template; glossy 3D cartoon; Pixar-like rendering; neon colors; rainbow gradient; glassmorphism; UI cards; perfectly symmetrical grid; identical rounded rectangles; stock education icons; generic smiling children; robot/AI imagery; overly clean digital lines; sterile white background; excessive decorations; random stickers; unrelated characters; photorealistic images; textbook screenshots used as worksheet illustrations.

## Required output

Return source diagnosis, Character Lock, Scene Lock, selected modules and rationale, illustration prompts/checks, worksheet structure, student copy, teacher notes, Teaching QA, Visual QA, and unresolved facts. Stop when source quality is insufficient instead of inventing content.
